# Задание 2.1 — Телефонная книга

## Назначение

Консольная программа на языке C для хранения и редактирования записей телефонной книги. Список контактов хранится в динамическом массиве.

## Возможности

- добавление нового контакта;
- просмотр всех сохранённых контактов;
- редактирование контакта по его номеру в списке;
- удаление контакта по его номеру;
- проверка обязательных полей: фамилии и имени;
- хранение необязательных полей: отчества, места работы и должности;
- хранение до пяти значений каждого типа: телефонов, адресов электронной почты, ссылок на социальные сети и профилей в мессенджерах.

При вводе нескольких телефонов, адресов или ссылок можно завершить ввод раньше лимита: для этого нужно оставить очередное значение пустым и нажать Enter.

## Структура проекта

- `main.c` — пользовательское меню, ввод данных и взаимодействие с пользователем.
- `contact.h`, `contact.c` — структура контакта, проверка корректности данных и вывод контакта.
- `phonebook.h`, `phonebook.c` — структура телефонной книги и операции над динамическим массивом контактов: инициализация, добавление, редактирование, удаление и освобождение памяти.
- `tests.c` — модульные тесты операций телефонной книги.
- `Makefile` — команды сборки, запуска тестов и очистки.

## Требования

- компилятор C (например, GCC или Clang);
- утилита `make`.

Используется стандарт C17.

## Сборка и запуск

```sh
make
./phonebook
```

После запуска появится меню:

1. Добавить контакт.
2. Показать все контакты.
3. Редактировать контакт.
4. Удалить контакт.
0. Выход.

При редактировании и удалении указывается номер контакта из отображаемого списка, начиная с 1.

## Запуск тестов

```sh
make test
```

Тесты проверяют основные операции с контактами, корректность данных и граничные случаи.

## Очистка результатов сборки

```sh
make clean
```

Команда удаляет исполняемые файлы и объектные файлы, созданные при сборке.
