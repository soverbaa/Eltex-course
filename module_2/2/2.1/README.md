# Телефонная книга (задание 2.1)

Консольная программа на C для хранения списка контактов.

## Возможности

- добавление, просмотр, редактирование и удаление контактов;
- обязательные фамилия и имя;
- необязательные отчество, место работы и должность;
- до пяти телефонов, адресов электронной почты, ссылок на соцсети и профилей мессенджеров на один контакт;
- динамический массив для списка контактов.

Чтобы закончить ввод телефонов, email-адресов, ссылок или профилей раньше лимита, оставьте очередное значение пустым и нажмите Enter.

## Сборка и запуск

```sh
make
./phonebook
```

## Запуск тестов

```sh
make test
```

## Очистка исполняемых файлов

```sh
make clean
```
