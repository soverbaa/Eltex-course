# Задание 4.1 — Телефонная книга на двухсвязном упорядоченном списке

## 1. Назначение

Доработка лабораторной работы 2.1. Вместо динамического массива для хранения контактов используется двухсвязный упорядоченный список.

Программа позволяет добавлять, просматривать, редактировать и удалять контакты, сохраняя их в алфавитном порядке.

## 2. Принцип работы

Для хранения контактов используется двухсвязный список.

Каждый узел `ContactNode` содержит:
- `data` — данные контакта;
- `prev` — указатель на предыдущий узел;
- `next` — указатель на следующий узел.

Структура `PhoneBook` содержит:
- `head` — указатель на первый элемент списка;
- `tail` — указатель на последний элемент списка;
- `size` — количество контактов.

Контакты упорядочиваются по фамилии, затем по имени и отчеству.

При добавлении нового контакта программа определяет его место в списке и устанавливает необходимые связи между соседними узлами.

При редактировании контакт удаляется со старой позиции и вставляется заново в соответствии с обновлёнными данными, чтобы сохранить порядок сортировки.

При удалении узла связи между соседними элементами обновляются, а память удалённого узла освобождается.

## 3. Возможности программы

- добавление контактов;
- просмотр списка контактов;
- редактирование существующих контактов;
- удаление контактов;
- автоматическая сортировка по фамилии, имени и отчеству;
- получение контакта по его позиции в списке;
- освобождение динамически выделенной памяти.

## 4. Структура проекта

- `main.c` — консольное меню, ввод и отображение контактов.
- `contact.h`, `contact.c` — структура контакта, проверка обязательных полей и вывод информации.
- `phonebook.h`, `phonebook.c` — структура двухсвязного списка и функции добавления, получения, редактирования, удаления и освобождения памяти.
- `tests.c` — модульные тесты операций со списком.
- `Makefile` — сборка программы, запуск тестов и очистка файлов.

## 5. Требования

- компилятор C (GCC или Clang);
- утилита `make`.

Используется стандарт C17.

## 6. Сборка и запуск

Для сборки программы:

```bash
make
```

Запуск:

```bash
./phonebook
```

После запуска появится консольное меню для работы с телефонной книгой.

## 7. Запуск тестов

```bash
make test
```

Тесты проверяют:
- добавление контактов;
- правильность сортировки;
- получение контакта по индексу;
- редактирование с сохранением порядка;
- удаление контактов;
- обработку некорректных индексов;
- освобождение памяти.

## 8. Очистка

```bash
make clean
```

Команда удаляет исполняемые файлы, тестовую программу и объектные файлы.
