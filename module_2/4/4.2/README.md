# Задание 4.2 — Очередь с приоритетом

## Назначение

Консольная программа на языке C, реализующая очередь сообщений с приоритетами. Каждое сообщение содержит текст и целочисленный приоритет от 0 до 255.

## Принцип работы

Очередь реализована в виде односвязного списка. При добавлении новый элемент вставляется так, чтобы элементы располагались по убыванию приоритета: в начале очереди находятся сообщения с наибольшим приоритетом.

Если несколько сообщений имеют одинаковый приоритет, они извлекаются в порядке добавления (FIFO). Таким образом, первым извлекается самое раннее добавленное сообщение среди сообщений с максимальным приоритетом.

## Реализованные операции

- `queue_init()` — инициализация пустой очереди;
- `queue_enqueue()` — добавление сообщения с заданным приоритетом;
- `queue_dequeue_first()` — извлечение первого сообщения очереди, то есть сообщения с наивысшим доступным приоритетом;
- `queue_dequeue_priority()` — извлечение первого сообщения с точно заданным приоритетом;
- `queue_dequeue_at_least()` — извлечение первого сообщения, приоритет которого не ниже заданного порога;
- `queue_print()` — вывод всех сообщений в порядке приоритета;
- `queue_free()` — освобождение памяти, занятой элементами очереди.

Приоритет вне диапазона `0–255`, пустой текст сообщения и некорректные аргументы не принимаются.

## Структура проекта

- `main.c` — пользовательское меню и обработка ввода.
- `queue.h`, `queue.c` — структура очереди и реализация операций над односвязным списком.
- `tests.c` — проверки операций очереди и имитация генерации сообщений с разными приоритетами.
- `Makefile` — сборка программы, запуск тестов и очистка.

## Требования

- компилятор C (например, GCC или Clang);
- утилита `make`.

Используется стандарт C17.

## Сборка и запуск

```sh
make
./priority_queue
```

После запуска доступны пункты меню:

1. Добавить сообщение.
2. Извлечь первое сообщение.
3. Извлечь сообщение с заданным приоритетом.
4. Извлечь сообщение с приоритетом не ниже заданного.
5. Показать очередь.
0. Выход.

Для каждого сообщения вводятся непустой текст и приоритет от 0 до 255.

## Запуск тестов

```sh
make test
```

Тесты проверяют добавление сообщений, сортировку по приоритету, порядок FIFO для одинаковых приоритетов, все три способа извлечения, обработку пустой очереди и некорректного приоритета. Дополнительно выполняется имитация генерации сообщений со случайными приоритетами (с фиксированным начальным значением генератора для повторяемости результата).

## Очистка результатов сборки

```sh
make clean
```

Команда удаляет исполняемые файлы и объектные файлы, созданные при сборке.
