# Задание 4.3 — Телефонная книга на бинарном дереве поиска

## 1. Назначение

Доработка лабораторной работы 2.1. Вместо динамического массива для хранения контактов используется бинарное дерево поиска. Для ограничения высоты дерева реализована периодическая балансировка.

Программа позволяет добавлять, просматривать, редактировать и удалять контакты.

## 2. Принцип работы

Для хранения контактов используется бинарное дерево поиска.

Каждый узел `TreeNode` содержит:
- `data` — данные контакта;
- `left` — указатель на левое поддерево;
- `right` — указатель на правое поддерево.

Структура `PhoneBook` хранит указатель на корень дерева и дополнительную информацию, необходимую для управления деревом и балансировкой.

Ключ сортировки — фамилия, затем имя и отчество.

При добавлении контакта выполняется сравнение с текущим узлом:
- если новый контакт меньше текущего, он помещается в левое поддерево;
- если больше или равен текущему, он помещается в правое поддерево.

Для получения контактов в отсортированном порядке используется симметричный обход дерева (in-order): сначала обходится левое поддерево, затем текущий узел, затем правое поддерево.

Таким образом, контакты отображаются в алфавитном порядке.

## 3. Балансировка дерева

Для ограничения высоты дерева реализована периодическая балансировка.

После каждых пяти успешных изменений дерева (добавления или удаления) автоматически вызывается функция `book_balance()`.

Балансировка выполняется в два этапа:

1. С помощью симметричного обхода все контакты копируются во временный массив в отсортированном порядке.
2. Из массива рекурсивно строится сбалансированное дерево: средний элемент становится корнем, левая половина массива формирует левое поддерево, правая половина — правое.

Также предусмотрена возможность ручного вызова балансировки.

После успешной балансировки счётчик изменений сбрасывается.

## 4. Возможности программы

- добавление контактов;
- просмотр контактов в отсортированном порядке;
- редактирование контактов;
- удаление контактов;
- поиск контактов по позиции в отсортированном представлении;
- автоматическая балансировка после заданного количества изменений;
- ручная балансировка дерева;
- освобождение динамически выделенной памяти.

## 5. Структура проекта

- `main.c` — консольное меню, ввод и отображение контактов.
- `contact.h`, `contact.c` — структура контакта, проверка обязательных полей и вывод информации.
- `phonebook.h`, `phonebook.c` — структура бинарного дерева поиска, операции добавления, получения, редактирования, удаления и балансировки.
- `tests.c` — тесты операций с деревом и проверки балансировки.
- `Makefile` — сборка программы, запуск тестов и очистка файлов.

## 6. Требования

- компилятор C (GCC или Clang);
- утилита `make`.

Используется стандарт C17.

## 7. Сборка и запуск

Для сборки программы выполните:

```bash
make
```

Запуск:

```bash
./phonebook
```

После запуска появится консольное меню для работы с телефонной книгой.

## 8. Запуск тестов

```bash
make test
```

Тесты проверяют:
- добавление контактов;
- получение контактов в отсортированном порядке;
- редактирование контактов;
- удаление контактов;
- автоматический запуск балансировки после пяти успешных изменений;
- ручную балансировку;
- корректность освобождения памяти.

## 9. Очистка

```bash
make clean
```

Команда удаляет исполняемые файлы, тестовую программу и объектные файлы.
