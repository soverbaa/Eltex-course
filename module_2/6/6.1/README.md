# Задание 6.1 — Телефонная книга со статической библиотекой

## 1. Назначение

Доработка лабораторной работы 4.1. Телефонная книга использует двухсвязный упорядоченный список для хранения контактов, а структуры и функции для работы со списком вынесены в отдельную статическую библиотеку `libphonebook.a`.

Основная программа использует библиотеку для выполнения операций над контактами.

## 2. Принцип работы

Для хранения контактов используется двухсвязный упорядоченный список.

Каждый узел содержит:
- `data` — данные контакта;
- `prev` — указатель на предыдущий узел;
- `next` — указатель на следующий узел.

Контакты располагаются по возрастанию фамилии, имени и отчества.

При добавлении и редактировании контактов поддерживается порядок сортировки. При удалении узла обновляются связи между соседними элементами, после чего освобождается занимаемая им память.

### Создание статической библиотеки

Реализация работы с телефонной книгой находится в файлах `phonebook.c` и `contact.c`.

Процесс создания библиотеки состоит из нескольких этапов:

1. Исходные файлы компилируются в объектные файлы `.o`.
2. Утилита `ar` объединяет объектные файлы в статическую библиотеку `libphonebook.a`.
3. Основная программа и тесты компилируются с подключением созданной библиотеки.

Для подключения библиотеки используются параметры компилятора `-L.` и `-lphonebook`.

Статическая библиотека включается в исполняемый файл на этапе компоновки.

## 3. Возможности программы

- добавление контактов;
- просмотр списка контактов;
- редактирование контактов;
- удаление контактов;
- автоматическая сортировка по фамилии, имени и отчеству;
- получение контакта по позиции;
- использование функций телефонной книги через статическую библиотеку;
- освобождение динамически выделенной памяти.

## 4. Структура проекта

- `main.c` — консольное меню, ввод и отображение контактов.
- `phonebook.h`, `phonebook.c` — структуры и функции для работы с двухсвязным упорядоченным списком.
- `contact.h`, `contact.c` — структура контакта, проверка данных и вывод информации.
- `tests.c` — модульные тесты операций телефонной книги.
- `Makefile` — компиляция объектных файлов, создание статической библиотеки, сборка программы и тестов.

## 5. Требования

- компилятор C (GCC или Clang);
- утилита `make`;
- утилита `ar` для создания статической библиотеки.

Используется стандарт C17.

## 6. Сборка и запуск

Для сборки программы и статической библиотеки выполните:

```bash
make
```

В результате будет создана библиотека:

```text
libphonebook.a
```

Запуск программы:

```bash
./phonebook
```

## 7. Запуск тестов

```bash
make test
```

Тесты проверяют:
- добавление контактов;
- сортировку;
- получение контакта по позиции;
- редактирование с повторной вставкой в отсортированное место;
- удаление контактов;
- корректность работы функций через статическую библиотеку.

## 8. Очистка

```bash
make clean
```

Команда удаляет исполняемые файлы, тестовую программу, объектные файлы и статическую библиотеку.

При следующем запуске `make` библиотека будет собрана заново.
