# Задание 6.2 — Телефонная книга с динамической библиотекой

## 1. Назначение

Доработка лабораторной работы 6.1. Для хранения контактов используется двухсвязный упорядоченный список, а структуры и функции для работы со списком находятся в отдельной динамической библиотеке.

Основная программа использует динамическую библиотеку `libphonebook` для выполнения операций над контактами.

## 2. Принцип работы

Для хранения контактов используется двухсвязный упорядоченный список.

Каждый узел содержит:
- `data` — данные контакта;
- `prev` — указатель на предыдущий узел;
- `next` — указатель на следующий узел.

Контакты располагаются по возрастанию фамилии, имени и отчества.

При добавлении нового контакта определяется его место в списке. При редактировании контакт повторно вставляется в соответствии с обновлёнными данными. При удалении узла обновляются связи между соседними элементами, а занимаемая память освобождается.

### Создание динамической библиотеки

Реализация работы с телефонной книгой находится в файлах `phonebook.c` и `contact.c`.

При сборке исходные файлы компилируются непосредственно в динамическую библиотеку.

В зависимости от операционной системы используется соответствующий формат:

- macOS — `libphonebook.dylib`;
- Linux — `libphonebook.so`.

Основная программа и тесты компонуются с динамической библиотекой.

Для подключения используются параметры `-L.` и `-lphonebook`.

В Makefile также задаётся путь поиска библиотеки относительно исполняемого файла:
- `@loader_path` для macOS;
- `$ORIGIN` для Linux.

Это позволяет запускать программу из каталога задания без дополнительной настройки переменных окружения.

## 3. Возможности программы

- добавление контактов;
- просмотр списка контактов;
- редактирование контактов;
- удаление контактов;
- автоматическая сортировка по фамилии, имени и отчеству;
- получение контакта по позиции;
- использование функций телефонной книги через динамическую библиотеку;
- освобождение динамически выделенной памяти.

## 4. Структура проекта

- `main.c` — консольное меню, ввод и отображение контактов.
- `phonebook.h`, `phonebook.c` — структуры и функции для работы с двухсвязным упорядоченным списком.
- `contact.h`, `contact.c` — структура контакта, проверка данных и вывод информации; реализации включаются в динамическую библиотеку.
- `tests.c` — тесты операций телефонной книги через динамическую библиотеку.
- `Makefile` — сборка динамической библиотеки, основной программы и тестов для macOS и Linux.

## 5. Требования

- macOS или Linux;
- компилятор C (GCC или Clang);
- утилита `make`.

Используется стандарт C17.

## 6. Сборка и запуск

Для сборки программы и динамической библиотеки выполните:

```bash
make
```

В зависимости от операционной системы будет создан один из файлов:

```text
libphonebook.dylib
```

или

```text
libphonebook.so
```

Запуск программы:

```bash
./phonebook
```

## 7. Запуск тестов

```bash
make test
```

Тесты проверяют:
- добавление контактов;
- сортировку;
- получение контакта по позиции;
- редактирование с повторной вставкой в отсортированное место;
- удаление контактов;
- корректность работы функций через динамическую библиотеку.

## 8. Очистка

```bash
make clean
```

Команда удаляет исполняемые файлы, тестовую программу, объектные файлы и динамические библиотеки.

При следующем запуске `make` библиотека будет собрана заново.
