# Задание 6.3 — калькулятор с динамической загрузкой операций

Каждая операция находится в отдельной динамической библиотеке. Все библиотеки экспортируют функцию `calc_operation(double, double, double *)`.

## Сборка на macOS

```bash
make clean
make
./calculator ./plugins
```

На macOS создаются файлы `.dylib`. На Linux Makefile автоматически создаёт `.so`.

Можно передать другой каталог с библиотеками первым аргументом:

```bash
./calculator ./my_plugins
```

## Как устроено решение

- `plugin_api.h` — общий интерфейс функции, которую экспортирует каждая библиотека.
- `plugins/add.c`, `sub.c`, `mul.c`, `div.c` — по одной операции в каждом исходном файле и в каждой собранной библиотеке.
- `plugin_loader.c` — просмотр каталога, `dlopen()` и `dlsym()`.
- `calc.c` — динамический массив операций и освобождение ресурсов.
- `main.c` — меню и вызов выбранной функции через указатель.

При завершении программы сначала закрываются все загруженные библиотеки через `dlclose()`, затем освобождается массив операций.
