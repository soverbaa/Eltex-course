# Задание 6.3 — Калькулятор с динамической загрузкой операций

## Назначение

Консольный калькулятор на языке C, который загружает математические операции из динамических библиотек во время запуска программы. Каждая операция собирается в отдельную библиотеку, а основной исполняемый файл не содержит её реализации.

## Принцип работы

1. При запуске программа открывает каталог с динамическими библиотеками.
2. Загрузчик перебирает файлы каталога и выбирает библиотеки с расширением `.dylib` на macOS или `.so` на Linux.
3. Каждая библиотека загружается с помощью `dlopen()`.
4. С помощью `dlsym()` загрузчик получает адрес функции `calc_operation`.
5. Найденная функция и дескриптор библиотеки сохраняются в структуре операции калькулятора.
6. Пользователь выбирает операцию в меню, после чего она вызывается через указатель на функцию.
7. При завершении работы калькулятор освобождает массив операций и выгружает подключённые библиотеки.

Все библиотеки используют общий интерфейс, объявленный в `plugin_api.h`:

```c
int calc_operation(double a, double b, double *result);
```

Функция возвращает ненулевое значение при успешном выполнении операции и `0`, если выполнить её нельзя. Например, деление возвращает ошибку при делении на ноль.

## Реализованные операции

- сложение (`add`);
- вычитание (`sub`);
- умножение (`mul`);
- деление (`div`).

## Структура проекта

- `main.c` — меню калькулятора, ввод чисел и вызов выбранной операции.
- `calc.h`, `calc.c` — структуры калькулятора и операций, управление динамическим массивом операций и освобождение ресурсов.
- `plugin_loader.c` — поиск, загрузка библиотек и получение адресов функций.
- `plugin_api.h` — общий интерфейс, которому соответствует функция в каждой библиотеке.
- `plugins/add.c`, `plugins/sub.c`, `plugins/mul.c`, `plugins/div.c` — исходные файлы отдельных операций.
- `tests.c` — тесты загрузки библиотек и проверки результатов операций.
- `Makefile` — сборка калькулятора, динамических библиотек и тестов.

## Требования

- macOS или Linux;
- компилятор C (например, Clang или GCC);
- утилита `make`.

Используется стандарт C17 и POSIX-интерфейс динамической загрузки библиотек (`dlopen`, `dlsym`, `dlclose`). Makefile автоматически выбирает расширение динамических библиотек и параметры сборки для macOS или Linux.

## Сборка и запуск

```sh
make
```

Команда собирает исполняемый файл `calculator` и библиотеки операций в каталоге `plugins/`.

Запуск с каталогом плагинов по умолчанию:

```sh
./calculator
```

Можно явно указать каталог с библиотеками:

```sh
./calculator ./plugins
```

После загрузки библиотек программа выведет список доступных операций. Выберите номер операции, затем введите два вещественных числа. Для выхода выберите `0`.

## Запуск тестов

```sh
make test
```

Команда собирает программу и динамические библиотеки, затем запускает тесты. Проверяется загрузка четырёх операций, корректность результатов сложения, вычитания, умножения и деления, обработка деления на ноль и освобождение ресурсов калькулятора.

## Очистка результатов сборки

```sh
make clean
```

Команда удаляет исполняемые файлы и собранные динамические библиотеки. При следующей сборке они будут созданы заново.
