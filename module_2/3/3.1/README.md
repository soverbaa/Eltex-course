# Задание 3.1 — Моделирование изменения прав доступа (chmod)

## Назначение

Консольная программа на языке C для разбора, отображения и изменения девяти стандартных битов прав доступа Unix-файлов. Программа моделирует работу символьных команд `chmod`, но не изменяет права реального файла.

## Возможности

- ввод прав в цифровом формате, например `755` или `0644`;
- ввод прав в символьном формате, например `rwxr-xr-x`;
- вывод прав в трёх представлениях: символьном, восьмеричном и побитовом;
- получение текущих прав существующего файла с помощью `stat()`;
- изменение сохранённой маски прав с помощью команд, аналогичных символьной форме `chmod`;
- поддержка субъектов `u` (владелец), `g` (группа), `o` (остальные), `a` (все);
- поддержка операций `+` (добавить права), `-` (убрать права) и `=` (назначить права);
- обработка нескольких команд, разделённых запятыми, например `g-w,o=r`;
- проверка некорректного ввода.

**Важно:** пункт меню с `stat()` только считывает информацию о файле. Команда модификации меняет маску внутри программы и не вызывает системный `chmod()` для изменения реального файла.

## Структура проекта

- `main.c` — меню программы, ввод исходных прав или имени файла и вызов функций обработки.
- `permissions.h`, `permissions.c` — преобразование прав между форматами, их вывод и применение символьных команд.
- `test_permissions.c` — модульные тесты разбора прав и обработки команд.
- `Makefile` — сборка программы, запуск тестов и очистка.

## Требования

- Unix-подобная операционная система (например, Linux или macOS);
- компилятор C (например, GCC или Clang);
- утилита `make`.

Используется стандарт C17 и системные интерфейсы `stat()` / `mode_t`.

## Сборка и запуск

```sh
make
./lab3_1
```

### Работа с программой

После запуска доступны пункты меню:

1. **Ввести права и показать представления.** Введите, например, `755`, `0644` или `rwxr-xr-x`.
2. **Получить права файла через `stat()`.** Введите путь к существующему файлу. Программа выведет его права в трёх форматах.
3. **Изменить права с помощью команды chmod.** Сначала необходимо выполнить пункт 1 или 2, чтобы задать исходную маску. Затем введите команду, например `u+x` или `g-w,o=r`.
0. **Выход.**

Примеры символьных команд:

| Команда | Действие |
|---|---|
| `u+x` | добавить владельцу право на выполнение |
| `g-w` | убрать у группы право на запись |
| `o=r` | назначить остальным только право на чтение |
| `a-w` | убрать право на запись у всех |
| `g=` | убрать у группы все права |

## Запуск тестов

```sh
make test
```

Тесты проверяют преобразование цифровой и символьной записи, отклонение некорректных значений, добавление и удаление прав, операцию назначения `=`, последовательное применение нескольких команд и сохранение исходной маски при ошибке.

## Очистка результатов сборки

```sh
make clean
```

Команда удаляет исполняемые и объектные файлы, созданные при сборке.
